# 四彩牌牌面

`four-colour-cards.webp` 取自 VerzatileDev 的 [4 Colour Cards](https://verzatiledev.itch.io/4colour)。作者在该产品页与 [2026-03-03 的更新公告](https://verzatiledev.itch.io/4colour/devlog/1447489/now-cc0-license) 标明采用 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。

本项目使用[固定版本镜像](https://github.com/zhuyinghua6961/UNO/tree/e92472a96854ad12f0137242bcf77493adca1552/assets/ready/cards)中的 55 张 PNG，仅取牌面和牌背。把它们统一缩为 160 × 250 像素，合成无损 WebP。按红、黄、绿、蓝排前四行，每行依次是 0–9、跳过、反转、+2。最后一行的前三列是牌背、变色、变色 +4。
