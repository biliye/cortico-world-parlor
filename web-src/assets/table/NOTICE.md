# 桌面绒布底图

`cloth.webp` 是图像生成模型产出的深绿绒布纹理，用作麻将牌桌与手牌台的背景，不参与任何逻辑。

- **生成**：1536×1024 原图，提示词要求「俯视绒布、无物体、无文字、可平铺」
- **处理**：裁掉原图右下角的生成水印 → `eq=gamma=1.42:contrast=0.94:saturation=1.1` 提亮（原图四角压得很暗，直接铺会发脏）→ 缩放到 1104×808 → WebP q82（约 74 KB）
- **用法**：`MahjongGame.vue` 通过 CSS 变量 `--mj-cloth-img` 注入；牌桌取 `130%` 放大只取中心（避开原图暗角），手牌台取 `cover` 并对齐偏上；变量缺失时回落到 `--mj-cloth` 纯色，不影响可读性
