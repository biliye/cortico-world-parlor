# 麻将桌面素材

`mahjong-board.webp` 来自本次用户提供的桌面图，保留原尺寸和完整边框，压为 WebP 用作主桌背景。

`cloth.webp` 是图像生成模型产出的深绿绒布纹理，用作麻将手牌台背景。

- **生成**：1536×1024 原图，提示词要求「俯视绒布、无物体、无文字、可平铺」
- **处理**：裁掉原图右下角的生成水印 → `eq=gamma=1.42:contrast=0.94:saturation=1.1` 提亮（原图四角压得很暗，直接铺会发脏）→ 缩放到 1104×808 → WebP q82（约 74 KB）
- **用法**：手牌台取 `cover` 并对齐偏上，背景图缺失时回落到深绿色。
